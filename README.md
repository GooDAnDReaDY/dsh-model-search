# @goodandready-private/dsh-model-search

Плагин для DeepSeek Harness WebUI: быстрый живой поиск и фильтрация моделей в выпадающем списке выбора модели.

## Возможности

- 🔍 **Мгновенная фильтрация**: поиск по названию модели, техническому идентификатору (ID) и имени провайдера на лету.
- 🛡️ **Защита от изменений ядра DSH**: поиск устойчив к смене внутренних CSS-модулей ядра благодаря использованию нативного текстового содержимого (`textContent` + `title`).
- 🔀 **Многословный поиск с пунктуацией**: поддержка запросов через пробел, запятую, слэш или точку с запятой (`deepseek, flash`, `qwen/coder`).
- ⌨️ **Двусторонняя автокоррекция раскладки**: находит модели независимо от активного языка клавиатуры (`вуузыуул` находит `DeepSeek`, `пзе-4щ` находит `gpt-4o`, `zyltrc` находит `Яндекс`).
- 🗣️ **Расширенные русские фонетические алиасы**: понимает названия моделей и модификаторы (`дипсик`, `гпт`, `клод`, `сонет`, `опус`, `хайку`, `квен`, `гемини`, `флеш`, `грок`, `оллама`, `ризонер`, `мини`, `нано`, `макс` и др.).
- 🎯 **Умная навигация стрелками и доступность**: стрелки вверх/вниз переключают только видимые отфильтрованные модели; синхронизация `aria-hidden` и семантическая разметка `role="search"`.
- ⚡ **Высокая производительность**: троттлинг через `requestAnimationFrame` исключает нагрузку на CPU во время стриминга ответов в чате.
- 📐 **Полная совместимость с актуальным DSH**: корректная работа с двухуровневым селектором моделей (`root` <-> `model` <-> `effort`).
- 🌐 **Мультиязычность**: нативная поддержка русского, английского и китайского интерфейсов.
- 🎨 **Нативная тема**: строгое использование официальных токенов темы DSH (светлая/тёмная).

## Установка

```bash
dsh plugin --profile web add @goodandready-private/dsh-model-search@0.1.3
```

```bash
# Проверка синтаксиса
```
