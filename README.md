# @goodandready-private/dsh-model-search

Плагин для DeepSeek Harness WebUI: быстрый живой поиск и фильтрация моделей в выпадающем списке выбора модели.

## Возможности

- 🔍 **Мгновенная фильтрация**: поиск по названию модели, техническому идентификатору (ID) и имени провайдера на лету.
- 🔀 **Многословный поиск**: поддержка запросов из нескольких слов в любом порядке (например, `flash deepseek` найдет `DeepSeek-V4-Flash`).
- ⌨️ **Автокоррекция раскладки**: поиск находит модели, даже если вы забыли переключить язык клавиатуры (например, `вуузыуул` находит `DeepSeek`, а `пзе-4щ` находит `gpt-4o`).
- 🗣️ **Русские фонетические алиасы**: находит модели по привычным названиям (`дипсик`, `гпт`, `клод`, `сонет`, `квен`, `гемини`, `флеш`, `мини` и др.).
- 🎯 **Умная навигация стрелками**: перемещение стрелками вверх/вниз переключает только видимые отфильтрованные модели без «проваливания» фокуса в скрытые элементы.
- ⚡ **Высокая производительность**: троттлинг через `requestAnimationFrame` исключает нагрузку на CPU во время стриминга ответов в чате.
- 🛡️ **Безопасная интеграция с React**: фильтрация через стили без физической перестановки DOM-узлов ядра (предотвращает React Error #310).
- 📐 **Полная совместимость с актуальным DSH**: корректная работа с двухуровневым селектором моделей (`root` <-> `model` <-> `effort`).
- 🌐 **Мультиязычность**: нативная поддержка русского, английского и китайского интерфейсов.
- 🎨 **Нативная тема**: строгое использование официальных токенов темы DSH (светлая/тёмная).

## Установка

```bash
dsh plugin --profile web add @goodandready-private/dsh-model-search@0.1.2
```

```bash
# Проверка синтаксиса
```
